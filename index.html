🔌 Cho AI Agent truy cập kho từ điển

  
File HTML này lưu dữ liệu trong trình duyệt nên Agent không tự đọc được. Cách làm: đồng bộ kho lên Drive (glossary.json) qua Apps Script; Agent gọi API của script để tra từ.

  
  1. Dán mã bên dưới vào script.google.com, đổi 2 token, cấp quyền và Deploy như hướng dẫn ở ⚙️ (nếu đã có script cũ: thay mã rồi Deploy Phiên bản mới).
    2. 
  
  2. Bấm ⚙️ URL & Token, nhập URL /exec và TOKEN (quản trị).
  3. Bấm Đẩy kho lên Drive. Mỗi lần sửa kho thì đẩy lại (đẩy sẽ ghi đè bản trên Drive).

  

 
Mã Apps Script (kho từ điển + đọc Drive)
  
const TOKEN='doi-chuoi-bi-mat-nay',AGENT_TOKEN='token-rieng-cho-agent';
const out=o=>ContentService.createTextOutput(JSON.stringify(o)).setMimeType(ContentService.MimeType.JSON);
const dbf=()=>{const i=DriveApp.getFilesByName('glossary.json');return i.hasNext()?i.next():DriveApp.createFile('glossary.json','[]')};
const load=()=>JSON.parse(dbf().getBlob().getDataAsString());
const NA=/[^\x00-\x7f]/;
const rx=v=>new RegExp('\\b'+v.replace(/[.*+?^${}()|[\]\\]/g,'\\$&')+'\\b');
const vars=t=>String(t.english||'').split('/').map(s=>s.trim().toLowerCase()).filter(s=>s.length>2).concat([t.hanzi,String(t.hanviet||'').toLowerCase()]).filter(Boolean);
const hit=(t,low)=>vars(t).some(v=>NA.test(v)?low.indexOf(v)>=0:rx(v).test(low));
function lookup(txt,sect,deep,min){
 const low=txt.toLowerCase(),V=load().filter(t=>t.status==='verified'&&(!min||t.human||(t.conf||0)>=min)),seen={},res=[];
 [V.filter(t=>t.core),V.filter(t=>!t.core&&(!sect||t.sect===sect||t.sect==='Chung / Khái Quát')),V.filter(t=>!t.core)].slice(0,deep+1).forEach((L,i)=>L.forEach(t=>{
  if(!seen[t.id]&&hit(t,low)){seen[t.id]=1;res.push({tier:i+1,english:t.english,hanzi:t.hanzi,hanviet:t.hanviet,sect:t.sect,cat:t.cat,conf:t.conf,human:!!t.human,definition:t.definition})}}));
 return {ok:true,tiers_searched:deep+1,count:res.length,glossary:res}}
function handle(p){
 try{
  if(p.token!==TOKEN&&!(p.token===AGENT_TOKEN&&p.action==='lookup'))return out({ok:false,error:'Sai token'});
  const a=p.action||(p.id?'file':'ping');
  if(a==='ping')return out({ok:true});
  if(a==='lookup')return out(lookup(p.text||'',p.sect||'',Math.min(+p.deep||0,2),+p.minconf||0));
  if(a==='pull')return out({ok:true,terms:load()});
  if(a==='push'){dbf().setContent(JSON.stringify(p.terms));return out({ok:true,n:p.terms.length})}
  if(a==='folder'){const it=DriveApp.getFolderById(p.id).getFiles(),L=[];while(it.hasNext()){const f=it.next();L.push({id:f.getId(),name:f.getName(),size:f.getSize()})}return out({ok:true,files:L})}
  if(a==='url'){const r=UrlFetchApp.fetch(p.u,{muteHttpExceptions:true,followRedirects:true}),h=r.getHeaders(),m=String(h['Content-Type']||h['content-type']||'').split(';')[0],n=decodeURIComponent(p.u.split('?')[0].split('/').pop())||'link';
   return out(/^text\//.test(m)?{ok:true,name:n,mime:m,text:r.getContentText()}:{ok:true,name:n,mime:m,b64:Utilities.base64Encode(r.getContent())})}
  const f=DriveApp.getFileById(p.id),m=f.getMimeType(),n=f.getName();let t;
  if(m===MimeType.GOOGLE_DOCS)t=DocumentApp.openById(p.id).getBody().getText();
  else if(m===MimeType.GOOGLE_SHEETS)t=SpreadsheetApp.openById(p.id).getSheets().map(s=>s.getDataRange().getValues().map(r=>r.join('\t')).join('\n')).join('\n\n');
  else if(m===MimeType.GOOGLE_SLIDES)t=SlidesApp.openById(p.id).getSlides().map(s=>s.getShapes().map(x=>x.getText().asString()).join('\n')).join('\n\n');
  else if(/^text\//.test(m))t=f.getBlob().getDataAsString();
  if(t!=null)return out({ok:true,name:n,mime:'text/plain',text:t});
  return out({ok:true,name:n,mime:m,b64:Utilities.base64Encode(f.getBlob().getBytes())});
 }catch(err){return out({ok:false,error:String(err)})}}
function doGet(e){return handle(e.parameter)}
function doPost(e){return handle(JSON.parse(e.postData.contents))}

 
Cách Agent tra theo tầng (tiết kiệm token)
  
Agent không đọc cả kho: server tự khớp đoạn văn với từ điển và chỉ trả những thuật ngữ có trong đoạn (vài chục dòng). AGENT_TOKEN chỉ cho phép tra từ, không đọc được Drive của bạn — hãy đưa token này cho Agent, giữ TOKEN quản trị cho riêng bạn.

  
Trước khi dịch MỖI đoạn, gọi API kho từ điển:
POST URL_WEB_APP  (body JSON)
{"token":"AGENT_TOKEN","action":"lookup","text":"ĐOẠN NGUỒN","sect":"Tịnh Độ tông","deep":0,"minconf":80}  (minconf: chỉ nhận mục AI tin cậy ≥80% hoặc đã có người xác nhận)
- deep=0: chỉ quét Top thường dùng (tầng 1, rẻ nhất). Dùng kết quả này trước.
- Nếu đoạn còn thuật ngữ chuyên môn chưa có đối chiếu: gọi lại deep=1 (thêm thuật ngữ của tông phái/truyền thống), rồi deep=2 (toàn kho).
- Chỉ đưa các mục trong "glossary" trả về vào prompt dịch và bắt buộc dùng đúng thuật ngữ đó. Không tải cả kho.
- Thuật ngữ không có trong kho: giữ nguyên gốc kèm chú thích và ghi vào danh sách "cần bổ sung".

⚙️ Cầu nối Google Apps Script (đọc Doc riêng tư)

 
    
  
  1. Vào script.google.com → Dự án mới → dán mã ở tab 🔌 Kết nối Agent, đổi 2 token. Mã mới cần quyền Drive, Docs, Sheets, Slides và truy cập web: bấm Chạy lại để cấp quyền.
    2. 
  
  2. Cấp quyền: chọn hàm doGet → Chạy → Xem quyền → chọn tài khoản → Nâng cao → "Đi tới… (không an toàn)" → Cho phép. (Lỗi "e undefined" sau đó là bình thường.)
    3. 
  
  3. Triển khai → Ứng dụng web → Execute as: Me, Who has access: Anyone → Deploy → copy URL kết thúc bằng /exec.
    4. 
  
  4. Mỗi lần sửa mã: Triển khai → Quản lý triển khai → ✏️ → Phiên bản: Phiên bản mới → Deploy (URL giữ nguyên).
